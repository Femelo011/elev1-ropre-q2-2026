# ROPRE Quarter Visual Input - ELEV1 Elevate Incorporadora Q2/2026

## 1. Contexto do deck

Cliente ELEV1 (Elevate Incorporadora), frente Elevate Majestic. Check-in de Quarter Q2/2026 (abril-junho), 1º quarter operacional real (sem Q1 comparável). Fonte de conteúdo: `ropre-quarter-final.md`, aprovado por Felipe em 2026-07-27.

## 2. Fontes e confiabilidade

Mídia (Meta/Google) via NEKT - alta confiança. Funil comercial trimestral via retro/CRM - confiança média-alta. Sem logo de cliente disponível (não encontrado no deck prévio nem em nenhuma pasta local) - usar fallback textual "Elevate" no lugar do logo, marcado como pendência visual.

## 3. Ordem narrativa aprovada

Capa → Sumário ROPRE → Resultados (funil geral projetado vs realizado, funil Meta, funil Google, Google ad groups top, gargalos/restrição principal, plano 5W1H) → Criativos vencedores → Capa Objetivos → STEP do projeto → Objetivos Q2 (o que bateu) → Objetivos Q3 (SMART + OKRs) → Projeção Q3 → Capa Premissas e riscos → Premissas e riscos → Capa Entregas → Entregas → Capa Próximos passos → Backlog imediato → Obrigado.

Sem slide de "Q atual vs Q anterior" nem "mesmo período ano anterior" - não existe Q1 comparável (1º quarter operacional).
